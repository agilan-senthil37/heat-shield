# Urban shade survey zones

Pinpoint ranks dry open patches derived from 30 m pixels inside a 300 m analysis grid. The map publishes the largest connected patch per qualifying cell. Map links point to an interior point of that patch.

- Eligible pixels are mapped as developed open space, barren land, or grassland. Developed open space can include lawns near homes or parks. The screen excludes cropland, pasture, forest, and medium or high intensity development.
- FEMA USA Structures footprints get a five-meter screening buffer. Any pixel touched by that buffer or mapped water is removed. Protected land can pass only where NLCD classifies it as developed open space. Check park access and permission with the manager.
- The Landsat Normalized Difference Moisture Index uses scaled near-infrared and shortwave infrared reflectance. A value at or below zero passes this project's dry-ground screen. The index is a surface moisture signal for the scene date. Thirty-meter pixels can contain pavement or small structures, so field verification is required.
- Eligible pixels must have at least 40 °C surface temperature and at most 15% modeled canopy. The published score uses up to 60 points for temperature rank across the published candidates in each study area and up to 40 for canopy gap. Scores express local planting priority. Use ground temperature in °C to compare areas. The list shows up to 100 patches per study area and three per tract.
- Check surface type, ownership, permissions, utilities, sidewalk clearance, soil, and maintenance at the site.

Run `python scripts/cache_shade_moisture.py` to cache the reflectance bands. Run the generator from the backend checkout with `--current-local-sources` with the GIS requirements and the source cache and baseline bundle used by `scripts/environment.py`. It needs the regional NLCD rasters, qualifying Landsat scenes and their QA bands in `data/raw/environment`; vector boundaries use the same cache and are fetched if missing. Commit the generated `data/shade-zones.json` with the application when refreshing the snapshot. The public API serves it at `/api/shade-zones?study_area=...`; zone IDs also resolve via the existing detail, explanation and proposal APIs. Existing Census tract IDs still resolve for older records.

After building, run `python scripts/name_shade_zones.py`. It downloads the 2024 Census TIGER/Line county roads and California places into the ignored raw cache. Each name comes from the nearest named local or secondary road within 300 m (prefer roads intersecting the zone), and a city or census-designated place that contains the center. The label is a nearby reference for orientation, not an address, access point, or approved planting location.

Tracy and Mountain House include NLCD land-cover summaries for each cell and the surrounding ring of pixels in a 900 m square. Shares are calculated from recognized land-cover pixels and rounded separately. Coverage reports the portion of the window with recognized classes. Windows at the edge can extend beyond the downloaded raster, so the coverage value accompanies the surrounding shares. Tree-canopy, land-cover, and heat data do not measure local soil moisture or identify the cause of low canopy.

Tracy and Mountain House use Annual NLCD Collection 1.2 land cover for 2025, USDA Forest Service NLCD v2025-6 canopy for 2025, and the Landsat Collection 2 surface-temperature scene LC08_L2SP_044034_20260725_02_T1. That heat scene is a single summer observation. The land products represent the latest annual mapping year available when this snapshot was built. Source years are stored per zone.

To refresh these two areas, run `python scripts/refresh_local_shade_sources.py`, then `python scripts/build_shade_zones.py --refresh-local` and `python scripts/name_shade_zones.py`. The refresh keeps the existing candidate grid and updates its input measurements. The raster downloader pins the requested annual records and checks the numeric data before publishing its manifest.
